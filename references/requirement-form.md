# 页面需求表

## 1. 页面类型
- 例如：Dashboard / 列表页 / 表单页 / 详情页 / 登录页 / 移动端首页

## 2. 使用端
- Web Desktop / Mobile

## 3. 页面名称
- 例如：订单管理页 / 用户详情页 / 工作台首页

## 4. 页面主要目标
- 这个页面是给谁用的？
- 用户来到这个页面主要想完成什么？

## 5. 页面必须出现的区域
- 例如：顶部导航、侧边栏、筛选区、数据卡片、图表区、表格区、表单区、操作按钮

## 6. 页面必须出现的字段或信息
- 例如：订单号、用户名、手机号、状态、金额、创建时间

## 7. 风格要求
- 例如：简洁、企业后台、高信息密度、偏浅色、蓝白配色、稳重、不要花哨

## 8. 明确禁止出现的东西
- 例如：不要大圆角、不要毛玻璃、不要渐变、不要营销感

## 9. 参考对象（可选）
- 可以写产品名、页面名、截图说明

## 10. 是否允许我补全未说明区域
- 是 / 否

## 11. 输出精度
- 低保真 / 中保真 / 接近可开发视觉稿

## 12. 是否有参考截图
- 有 / 没有

## 13. 如果有参考截图，希望参考哪部分
- 结构参考 / 风格参考 / 结构 + 风格都参考

## 14. 参考截图中哪些内容不要照搬
- 例如：不要深色主题、不要大留白、不要复杂插画
